# Greyhaven Wardrobe v1.1.0 — Awareness & Semantic Icons

Changes over v1.0.0:

- Stronger wearer self-awareness of what is NOT being worn.
- Major visible absences are now explicitly salient to the roleplay:
  - no top / no bra with no upper cover
  - no bottom
  - barefoot / no footwear
  - no socks or hosiery
- Hidden absences such as no underwear under opaque clothing remain private self-knowledge unless visible or established.
- Reactions are context-sensitive: the AI is told not to ignore visible exposure, but also not to overreact every message.
- Detect-from-chat now distinguishes unknown categories from explicitly absent categories, so detecting "shorts" alone no longer falsely means every unmentioned garment is absent.
- Clothing choices now use subtype-appropriate semantic glyphs/emoji instead of repeating one unrelated category icon across every item.
- All 870 catalog options and all color choices are preserved.

Manual outfit saves are still COMPLETE:
if you save only an oversized T-shirt, every unselected primary clothing slot is intentionally absent.
If you save nothing, the character is explicitly naked.
Reset to Unknown remains separate.
